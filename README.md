# ساب‌ساز لایت — SubSaz Lite

پنل فوق‌سبک برای **Adobe Premiere Pro** که فایل زیرنویس فارسی (`.srt`) را به **لایه‌های گرافیکی MOGRT** تبدیل می‌کند — با استایلِ فایل گرافیکی خودتان و **معماری ضدکرش سه‌لایه**.

> این نسخه‌ی «لایت» عمداً ساده و کم‌دکمه است: فقط همان کاری که باید، بدون کرش.

---

## 🧩 نصب

1. **پریمیر را کاملاً ببندید.**
2. فایل ZIP را باز کنید و پوشه‌ی `com.srt2graphics.panel` را در این مسیر کپی کنید:

   ```
   %AppData%\Adobe\CEP\extensions
   ```

   (آدرس را در Run ویندوز بچسبانید: `%AppData%\Adobe\CEP\extensions`)
3. اگر قبلاً حالت دیباگ CEP را فعال نکرده‌اید، در رجیستری ویندوز مقدار `PlayerDebugMode` را برابر `1` قرار دهید:

   - `Win+R` → `regedit`
   - مسیر: `HKEY_CURRENT_USER\Software\Adobe\CSXS.11`
   - اگر کلید `CSXS.11` نیست، بسازید؛ سپس یک String Value با نام `PlayerDebugMode` و مقدار `1`
4. پریمیر را باز کنید: منوی **Window → Extensions → ساب‌ساز لایت**

> اگر پنل در منو دیده نشد: مسیر کپی را دوباره چک کنید که `com.srt2graphics.panel` مستقیم داخل `extensions` باشد، و مطمئن شوید پریمیر نسخه‌ی ۲۰۲۲+ (CSXS.11) است.

## 🚀 استفاده (سه قدم)

1. **فایل SRT**: روی «انتخاب SRT» بزنید و فایل زیرنویس فارسی را بدهید (پارسر داخل خود پنل است؛ BOM، CRLF، تگ‌ها و هم‌پوشانی ملایم خودکار مدیریت می‌شود).
2. **فایل MOGRT**: روی «انتخاب MOGRT» بزنید و همان فایل گرافیکی‌ای را بدهید که برای زیرنویس طراحی کرده‌اید.
3. **تبدیل**: ترک مقصد را انتخاب کنید، روی «ساخت لایه‌ها» بزنید و دست به پریمیر نزنید. پیشرفت را همان‌جا می‌بینید.

گزینه‌های ساده:
- **روش نوشتن متن**: پیش‌فرض «فقط بیکری — مطمئن‌ترین» است (v1.1.1)؛ متن هر زیرنویس داخل یک کپی اختصاصی از فایل قالب شما نوشته می‌شود (خارج از پریمیر، با موتور بیکری) و پریمیر فقط همان فایل‌ها را وارد می‌کند — مطمئن‌ترین روش، حتی روی پریمیرهایی که نوشتن اسکریپتیِ متن را نادیده می‌گیرند. فایل‌های بیکری در `Documents\SubSaz-Lite\Baked\` می‌مانند؛ آن پوشه را پاک نکنید (رسانه‌ی پروژه است).
- **ترک مقصد**: ترکی که لایه‌ها روی آن ساخته می‌شوند.
- **پاک‌سازی ترک مقصد**: فقط کلیپ‌های ساخته‌شده توسط همین پنل (با پیشوند `S2G|`) را پاک می‌کند؛ لایه‌های دستی شما دست‌نخورده می‌مانند.

## 🛡 معماری ضدکرش (چرا کرش نمی‌کند)

| # | سازوکار |
|---|---------|
| ۱ | **سه‌لایه‌ی جداست**: CEF (پارسر SRT + صف + UI فارسی) → ExtendScript (فقط-ASCII) → Scripting API پریمیر. کار سنگین روی میزبان است، JS فقط صف/انکودینگ. |
| ۲ | **صف تکی evalScript**: همیشه فقط یک فراخوانی در پرواز؛ نگهبان ۱۵ ثانیه‌ای جلوی قفل‌شدن صف را می‌گیرد. |
| ۳ | **چانک ۱۵تایی**: درج‌ها گروه‌گروه با نفس بین چانک‌ها انجام می‌شود، نه همه با هم. |
| ۴ | **ارسال فقط-ASCII**: متن فارسی به‌صورت escape امن (`\uXXXX`) وارد evalScript می‌شود؛ host اصلاً بایت غیر-ASCII ندارد. |
| ۵ | **ایزوله‌سازی خطا**: هر کیو (زیرنویس) در try/catch خودش است؛ خطای یکی، بقیه را نمی‌کُشد. |
| ۶ | **موتور بیکری (v1.1.0، پیش‌فرض)**: متنِ هر زیرنویس مستقیماً داخل یک کپی اختصاصی از فایل قالب نوشته می‌شود (خارج از پریمیر، در خود پنل) و پریمیر فقط همان فایل‌ها را وارد می‌کند — کلاً هیچ نوشتن متنی از اسکریپت داخل پریمیر انجام نمی‌شود؛ هر فایل شناسه‌های داخلی یکتا دارد تا درج پشت‌سرهم تصادم نکند. (از v1.1.1 بیکری تنها مسیر پیش‌فرض است؛ روش مستقیم فقط به‌صورت دستی قابل انتخاب است.) |
| ۷ | **سه لایه‌ی تعیین پایان کلیپ** (ticks → seconds → Time) تا متن از کادر بیرون نزند. |
| ۸ | **runId**: کش و متن قبلی بین اجراها باطل می‌شود تا داده‌ی کهنه نوشته نشود. |
| ۹ | **DUMP تشخیصی**: در اولین خطای غیرمنتظره، ساختار MOGRT یک‌بار ریز‌ریز ثبت می‌شود تا علت دقیق مشخص باشد. |
| ۱۰ | **پیام فارسی قابل‌فهم** برای هر خطا + جدا کردن ردیف‌های مشکل‌دار در پایان کار. |


## 📝 تغییرات v1.1.1

- **بیکری تنها مسیر پیش‌فرض شد**: در v1.1.0 اگر بیکری به هر دلیلی شکست می‌خورد (مثلاً Node بعد از نصبِ بدون ری‌استارتِ کامل پریمیر غیرفعال بود)، پنل بی‌صدا به روش مستقیم برمی‌گشت — همان روشی که روی برخی میزبان‌ها متن را نمی‌نویسد و باعث می‌شد «همه‌ی لایه‌ها متن قالب» به‌نظر برسد. حالا پیش‌فرض «فقط بیکری» است و شکست بیکری **بلند و فارسا** گزارش می‌شود با دقیقاً همین دستور: چه کاری باید بکنید.
- هر خطای بیکری ترجمه‌ی اختصاصی دارد (`trBakeErr`): Node غیرفعال → پریمیر را کامل ببندید و باز کنید؛ متن نمونه‌ی قالب خالی → داخل قالب متن بنویسید و دوباره اکسپورت کنید؛ و… .
- **نوار وضعیت پایانی همیشه نام موتورِ به‌کاررفته را نشان می‌دهد**: «(موتور بیکری)» یا «(موتور مستقیم)» — دیگر هرگز لازم نیست حدس بزنید فیکس در اجرا بوده یا نه.
- در حالت «هوشمند» (اختیاری) فال‌بک به مستقیم همچنان ممکن است، اما همیشه با خطای ثبت‌شده و هشدار پررنگ در وضعیت پایانی — فال‌بک بی‌صدا حذف شد.
- تست: ۱۰۲ + ۵۵ + ۴۳ PASS (سوئیت جدید `test_srt2graphics_v111.js`) + یکپارچه‌سازی SRT نمونه — همه سبز.

## 📝 تغییرات v1.1.0

- **رفع کامل باگ «متن داخل لایه‌ها همان متن قالب است»**: موتور بیکری اضافه شد — متن هر زیرنویس مستقیماً داخل یک کپی اختصاصی از فایل MOGRT نوشته می‌شود (خارج از پریمیر) و پریمیر فقط همان فایل‌ها را وارد می‌کند؛ دیگر هیچ نوشتن متنی از اسکریپت داخل پریمیر انجام نمی‌شود.
- متن‌های تکراری یک فایل مشترک دارند (بیک سریع‌تر + فایل کمتر برای پریمیر) و هر فایل شناسه‌های داخلی یکتا دارد (ضدکرش درج پشت‌سرهم — درس v2.4 پنل اصلی).
- پیش‌رفت مرحله‌ی بیکری جدا نشان داده می‌شود؛ اگر بیکری ممکن نباشد، صادقانه اعلام و به روش مستقیم (نوشتن چندمسیره‌ی v1.0.1) برمی‌گردد.
- پوشه‌ی فایل‌های بیکری: `Documents\SubSaz-Lite\Baked\` — رسانه‌ی پروژه است؛ پاکش نکنید (نگه‌داری ۶۰ روزه برای فایل‌های بلااستفاده).

## 📝 تغییرات v1.0.0

- انتشار اولیه‌ی نسخه‌ی لایت با معماری ضدکرش سه‌لایه (CEF / ExtendScript / Premiere).
- پارسر SRT سمت پنل: پشتیبانی از BOM و CRLF/CR، حذف تگ‌ها، مرتب‌سازی و شماره‌گذاری مجدد، رفع هم‌پوشانی ملایم.
- صف تکی evalScript با نگهبان ۱۵ ثانیه، چانک ۱۵تایی، encoding فقط-ASCII.
- نوشتن متن چه‌پاسه با readback و ری‌ترای؛ تعیین پایان کلیپ با سه لایه‌ی جایگزین.
- پاک‌سازی ایمن: فقط کلیپ‌های دارای پیشوند `S2G|`.
- رابط فارسی فوق‌سبک با فونت وزیرمتن (باندل‌شده).
